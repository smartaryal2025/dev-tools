Mastering Dev Notes

Dev Notes is a dual-engine documentation tool. It can instantly render your code into HTML, or work in reverse to extract clean Markdown out of messy MS Word documents and websites. Click the 🔄 Swap button in the top toolbar to switch modes and seamlessly transfer your work.

Mode 1 Standard Markdown Editor

Use the standard mode (MD ➔ HTML) to write your documentation from scratch. Type your raw Markdown on the left, and watch it turn into beautiful HTML on the right.

💻 Writing Code Blocks (Important!)

Since you are building a developer suite, you will frequently need to save blocks of code. To do this, you use triple backticks (the key usually above the Tab key: `).

Inline Code

For a quick variable name, wrap it in single backticks:
`const myVar = 10;` becomes const myVar = 10;

Multi-line Code Blocks

To write a full block of code, you must explicitly open and close the block.

  1. Type three backticks followed by the language name (e.g., ```javascript).
  2. Press Enter and paste your code.
  3. Press Enter again and type three backticks ``` alone on the final line to close the block!

🛠️ Toolbar & Autosave

  • 💾 Download .MD: Downloads your raw text exactly as you typed it. Perfect for pushing to GitHub.
  • 📋 Copy as HTML: Copies the rendered preview. If you paste this into an email or a WordPress blog, it keeps all your bolding, lists, and code blocks perfectly formatted!
  • ✔️ Autosave Enabled: Every time you press a key, your progress is saved to your browser's offline localStorage. If you accidentally close the tab, open it again and your text will be waiting for you.

Mode 2 The Reverse Converter (Word/HTML to Markdown)

If you have existing documentation in a Microsoft Word file, a Google Doc, or an old website, click the central 🔄 button to swap to Converter Mode. You don't need to rewrite anything in Markdown manually.

  • Importing MS Word: Click 📂 Import .DOCX / .HTML. The internal engine will automatically unzip the Word document, extract the text, and map the formatting (Headings, Bold, Lists, Tables) directly into pure Markdown on the right.
  • Rich Text Pasting: Alternatively, copy text directly from Wikipedia or a Word document and paste it into the left panel. The content-editable workspace retains the visual layout while the engine writes the Markdown for you seamlessly.
  • Raw HTML: You can also paste raw HTML source code (e.g., <div>Hello</div>). The tool will parse the DOM elements and strip away the tags, leaving only clean Markdown syntax.
